# Image Flow

**이미지 생성부터 비교와 수정까지, 한 프로젝트 안에서.**

Image Flow는 디자이너를 위한 Mac 앱입니다. 참조 이미지를 넣고 여러 결과를 만들어 비교하거나, 캔버스에서 작업 단계를 연결해 반복 작업을 이어갈 수 있습니다.

[다운로드 및 버전 안내](https://github.com/xtower-studio/gpt-image-flow/releases) · [문제 신고](https://github.com/xtower-studio/gpt-image-flow/issues)

## 설치하기

1. 위 **다운로드 및 버전 안내**에서 가장 최근 정식 버전의 `.dmg` 파일을 받으세요.
2. 내려받은 파일을 열고 **Image Flow를 Applications 폴더로 드래그**하세요.
3. Mac의 **응용 프로그램**에서 Image Flow를 실행하세요.

**macOS 14 이상**이 필요합니다. Universal 패키지는 Apple Silicon과 Intel Mac용 실행 파일을 모두 포함합니다. 실제 실행 검증은 Apple Silicon에서 진행합니다. macOS 26 이상에서는 Liquid Glass 디자인을 사용합니다.

> **0.13.0 배포 준비 중:** 다음모양 명의의 Developer ID 서명과 Apple 공증을 준비하고 있습니다. 이름에 `preview`가 들어간 DMG는 공증 전 검증용이며 일반 사용자용 정식 배포본이 아닙니다. 정식 DMG는 준비가 끝나면 위 Releases에 게시합니다. 앱을 사용하기 위해 Xcode나 개발 도구를 설치할 필요는 없습니다.

업데이트할 때는 생성 중인 작업을 마친 뒤 앱을 종료하고 새 앱으로 교체하세요. 선택한 보관함의 이미지와 작업 기록은 유지됩니다.

## 처음 시작하기

앱의 시작 안내에 따라 두 가지만 정하면 됩니다.

- **저장할 곳:** 기본 권장은 사용자 **그림(Pictures) → Image Flow**입니다. 원하는 폴더를 선택해도 됩니다.
- **생성 방식:** ChatGPT 계정으로 로그인하거나, 선택 사항인 OpenAI API를 연결하세요. 나중에도 설정에서 변경할 수 있습니다.

| 생성 방식 | 이런 때 사용하세요 | 필요한 연결 |
|---|---|---|
| 자동 | 적절한 모델을 자동으로 선택해 여러 결과를 보고 싶을 때 | ChatGPT 로그인 |
| 빠르게 | 빠르게 아이디어를 확인하고 싶을 때 | ChatGPT 로그인 |
| 고급 | 모델과 품질, 크기 등 세부 옵션을 직접 고르고 싶을 때 | OpenAI API 키 |

**API 사용료는 OpenAI가 직접 청구합니다. Image Flow는 어떠한 수수료도 받지 않습니다.** ChatGPT 구독과 API 요금은 별도입니다. API 키가 없어도 ChatGPT 방식으로 사용할 수 있으며, API만 사용할 때는 ChatGPT 로그인이 필요하지 않습니다. 실제 생성 가능 여부는 연결한 계정의 권한과 서비스 제한에 따릅니다.

## 첫 이미지 만들기

1. **프로젝트**를 만들고 원하는 이미지를 프롬프트에 설명하세요.
2. 참고할 이미지가 있다면 **프롬프트 영역으로 드래그**하세요. 첨부한 원본도 같은 프로젝트에 보관됩니다.
3. 생성 방식과 비율 등을 선택하고 **생성**을 누르세요. 단축키는 **⌘ Return**입니다.
4. 생성 중인 이미지마다 대기 카드가 나타납니다. 완료된 이미지는 **더블 클릭 또는 Space**로 크게 보세요. **←/→**로 앞뒤 이미지를 보고 **Space 또는 Esc**로 닫을 수 있습니다.
5. 마음에 드는 결과를 참조로 넣어 수정하거나, 여러 장을 선택해 비교하고 내보내세요.

자주 쓰는 프롬프트는 **레시피**로 저장하세요. 캔버스에서는 프롬프트·참조·생성 노드를 연결하고, 결과를 다음 단계의 입력으로 사용해 작업 흐름을 재사용할 수 있습니다.

## 내 파일은 어디에 있나요?

**설정 → 저장 공간 → 저장 폴더 열기**에서 찾을 수 있습니다.

```text
Image Flow/
├── 첫 프로젝트 — 식별자/
│   ├── 1-1.png
│   ├── 1-2.png
│   ├── 2-1.png
│   ├── 참조 이미지.png
│   └── .imageflow/                 숨김: 이미지별 생성 정보·프로젝트 설정
├── 다음 프로젝트 — 식별자/
│   └── …
└── .imageflow/                     숨김: 전체 보관함·작업 기록·복구 데이터
```

- 생성 이미지는 프로젝트 안에서 **요청 번호-이미지 번호**로 구분합니다. 다음 요청은 앞 번호를 이어 사용합니다.
- 이미지 안의 **이름을 클릭**하거나 설정 메뉴의 **이름 변경**을 선택하면 실제 파일명도 함께 바뀝니다. 같은 이름의 파일은 덮어쓰지 않습니다.
- **썸네일 파일을 만들지 않습니다.** 화면은 원본을 읽어 표시합니다.
- 프로젝트 폴더에는 생성 이미지와 첨부 원본만 보입니다. 프롬프트, 생성 옵션, 참조 연결 등은 `.imageflow` 폴더에 보관합니다. Finder에서 **⌘⇧.**으로 숨김 파일을 볼 수 있습니다.
- 기존 보관함은 첫 실행에서 원본 해시를 검증한 뒤 새 구조로 정리합니다. 기존 이름을 직접 바꾼 이미지는 그 이름을 유지합니다.
- **백업할 때는 Image Flow 폴더 전체를 복사하세요.** 내부 이미지만 골라 복사하면 숨김 복구 정보가 빠집니다. 다시 설치한 후 **설정 → 기존 보관함 열기**에서 백업 폴더를 선택하세요.
- 폴더 경로는 최초 이름과 식별자로 유지됩니다. 이름 변경은 앱에서 진행하세요.

API 키와 ChatGPT 로그인 정보는 보관함에 포함하지 않습니다. API 키는 macOS 키체인에 저장합니다. 이미지와 프롬프트는 생성할 때 연결한 ChatGPT 또는 OpenAI API로 전송됩니다.

## 문제가 생겼나요?

- **ChatGPT 연결이 풀렸어요:** 왼쪽 아래 **ChatGPT 연결**에서 다시 로그인하세요.
- **이미지 대신 답변이나 오류가 왔어요:** 작업 기록에서 내용을 확인하고 후속 작업을 이어가세요. 이미지 생성 도구 확인에 실패했다면 실제 ChatGPT 작업 화면에서 연결 상태를 확인하세요.
- **앱을 종료했는데 생성 중이었어요:** ChatGPT 작업의 **기존 결과 확인**으로 원래 대화의 결과를 확인하세요. 전송 여부가 불분명한 요청을 자동으로 다시 보내지 않습니다.
- **macOS가 저장한 API 키 접근을 물어요:** 새 서명으로 업데이트한 앱에서 기존 키를 처음 사용할 때 표시될 수 있습니다. 설치한 앱이 맞는지 확인한 뒤 허용하세요.
- **저장 폴더를 찾을 수 없어요:** 외장 드라이브를 연결하거나 **기존 보관함 열기**에서 원래 폴더를 다시 선택하세요.

해결되지 않으면 [Issues](https://github.com/xtower-studio/gpt-image-flow/issues)에 macOS 버전, 앱 버전, 오류 메시지를 남겨 주세요. API 키나 개인 작업 이미지는 올리지 마세요.
