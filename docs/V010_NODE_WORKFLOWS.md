# 0.10 노드 워크플로

캔버스는 이미지를 배치하는 보드에서, 입력과 생성 단계를 연결해 실행하는 작업 공간으로 바뀐다.

## 작업 흐름

1. 캔버스에서 **현재 설정으로 시작**하거나 **분기 워크플로 만들기**를 선택한다. 기존 프로젝트 프롬프트·참조·생성 설정을 가져오며, 생성은 자동으로 시작하지 않는다.
2. **공통 프롬프트**, **참조 이미지**, **생성 단계**를 추가한다. 파일을 캔버스에 드롭하거나 프로젝트 이미지에서 선택할 수 있다.
3. 오른쪽 출력 점을 다음 단계의 왼쪽 입력 점으로 드래그한다. 출력 → 입력 순서로 클릭하거나 입력 옆 메뉴로 연결·해제할 수도 있다. 보라색은 공통 지시, 파란색은 이미지다.
4. 생성 단계마다 지시·모드·비율·배경·API 옵션을 설정한다. 공통 지시는 앞에 붙고 해당 단계의 지시가 뒤에 붙는다. 여러 참조는 연결한 순서로 전달한다.
5. **흐름 실행**은 모든 생성 단계를 새로 한 번씩 실행한다. 실행 전에 단계 수·최대 이미지 수·API 유료 단계 여부를 확인한다. 실행 계획은 시작 시 고정한다.
6. 한 장의 결과는 다음 단계로 바로 전달한다. 여러 장이면 후보를 클릭해 한 장을 고를 때까지 연결된 단계가 기다린다. 병렬 분기는 같은 선택 결과를 참조로 사용한다.
7. **이 단계 실행**은 앞 단계의 선택한 기존 결과를 재사용해 해당 단계만 다시 실행한다. **결과에서 분기**는 결과를 참조하는 새 단계를 만들고, **복제**는 설정과 입력 연결을 복사한다.

## 보존과 실행 제어

- 그래프·위치·확대율은 프로젝트에 저장한다. 생성 이력과 결과는 기존 보관함·작업 기록에 남는다.
- 실행 중 노드 내용과 연결은 고정하지만 위치 이동과 결과 선택은 가능하다.
- 실패·로그인 필요·불확실한 완료·텍스트 응답에서는 연결된 후속 생성을 보내지 않는다. 노드에서 원인을 읽거나 실행 기록을 열 수 있다.
- 이미 보낸 요청을 자동 재전송하지 않는다. **후속 중단**은 아직 보내지 않은 작업을 취소하고, 이미 전송한 작업의 결과는 보존한다.
- 앱 재시작 시 실행 중 흐름은 일시정지한다. 기존 전송 여부는 기존 작업 복구 규칙을 따르며, 사용자가 계속 또는 중단을 선택한다.
- 새 전체 실행은 이전 실행 결과로 의존성을 충족하지 않는다. 명시적인 단계별 실행만 기존 결과를 재사용한다.
- 노드 삭제는 원본 이미지나 작업 기록을 삭제하지 않는다. 연결·배치·노드 편집은 되돌리기를 지원한다. 텍스트 편집은 편집기의 기본 되돌리기를 사용한다.
- **프로젝트로 복제**는 구조·설정·참조를 재사용하고 생성 기록 연결을 초기화한다. **이전 이미지 배치 보기**에서 기존 보드와 배치를 계속 사용할 수 있다.

## 범위

현재 노드는 공통 프롬프트·참조·생성이다. 로컬 확산 모델의 샘플러, 업스케일러, 마스킹 처리 등을 직접 실행하는 ComfyUI 호환 엔진은 아니다. 기존 ChatGPT/OpenAI 이미지 생성 엔진과 저장 공간을 사용한다. 다른 컴퓨터로 참조 파일까지 묶는 워크플로 패키지 내보내기는 아직 제공하지 않는다.

## 검증

- 그래프 연결 타입, 순환 차단, 삭제 시 연결 정리, 실행 순서.
- 이전 결과가 새 실행에 섞이지 않음, 단계별 기존 결과 재사용.
- 여러 결과의 명시적 선택, 한 결과 자동 전달, 두 분기의 같은 참조 공유.
- 실패·답변·부분 결과·취소 시 후속 실행 차단.
- 실행 설정 스냅샷, 직렬화 복원, 기존 프로젝트와 작업 기록 호환성.
- 전체 자동 테스트 62개 통과. 개발 Mac에서 빌드와 실제 실행을 확인했다.
- ChatGPT 빠르게 모드로 원본 → 두 변형의 병렬 분기 완료. 두 후속 요청의 참조 ID가 원본 결과 ID와 동일함을 확인했다.
- 변형 한 단계만 다시 실행했을 때 해당 단계의 요청만 추가됐으며 원본과 다른 분기는 재실행하지 않았다.
- 자동 모드에서 4장을 받았을 때 두 후속 단계에는 요청 ID가 없는 대기 상태가 유지됐다. 두 번째 후보를 클릭한 뒤 두 후속 요청에 동일한 선택 이미지 ID가 전달됐다.
- 출력에서 입력으로 실제 포트 드래그를 수행해 연결이 4개 → 5개로 늘고, ⌘Z로 4개로 돌아오는 것을 확인했다.
- 재실행과 앱 재시작 후 노드 5개·연결 4개·배치·기존 생성 기록이 복원됐다. 중단 전에 전송된 생성 결과도 보존됐다.
- 실제 검증에서 ChatGPT 요청 10회로 이미지 13장을 저장했다. 추가 유료 API 생성은 수행하지 않았다. API 경로는 기존 엔진과 옵션 검증을 사용한다.
