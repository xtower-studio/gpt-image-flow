# 0.11 — 온보딩, 복구 가능한 보관함과 생성 경험

## 실제 이미지 생성 도구 확인

2026-09-26 로그인된 WKWebView에서 새 요청을 준비하고 화면과 DOM을 함께 확인했다. 입력창 하단에 **이미지 생성** 배지가 표시됐으며 선택된 버튼의 접근성 이름은 **이미지 생성 제거**였다. 프롬프트를 채운 뒤에도 선택이 유지됐다. 이 검증은 전송 없이 수행했다.

로그인용 연결 창과 실제 생성용 워커 창은 별개다. 진행 중인 작업을 열고 **실제 ChatGPT 작업 화면 보기**를 누르면 해당 워커를 볼 수 있다. 준비가 검증된 작업에는 확인 시각을 저장하고 앱에서도 도구 적용 확인을 표시한다. 기존의 전송 직전 재검증을 유지한다.

빠르게(Instant)의 새 요청과 후속 요청에서는 앱이 `n=1`을 붙이지 않는다. 사용자 본문은 수정하지 않는다. 자동 요청의 `n=4`는 유지한다. 실제 Instant 생성 1회를 실행해 이미지 1장의 수집과 저장을 확인했다. 유료 API 생성은 이번 검증에서 실행하지 않았다.

## 첫 실행 안내

저장 위치 → 연결 → 첫 워크플로의 3단계다. ChatGPT와 OpenAI API는 각각 연결할 수 있고, 연결은 나중에 해도 된다. API 요금은 OpenAI가 직접 청구하고 앱 수수료가 없다는 안내를 포함한다. 설정에서 안내를 다시 열 수 있다.

기존 사용자의 첫 안내에서는 현재 보관함의 이미지 수와 복사할 위치를 보여 준다. 기본 권장은 `~/Pictures/Image Flow`. 폴더 변경 시 기존 폴더를 삭제하지 않는다.

## 사용자 보관함

설정 → 저장 공간에서 빈 폴더로 복사하거나 **기존 보관함 열기**로 복원한다. 생성·가져오기가 진행 중일 때는 변경을 막는다. 원본과 기록을 복사하고 SHA-256 해시를 검증한 다음 사용 위치를 전환한다. 실패하면 현재 보관함을 유지한다. 복원한 대기열은 사용자가 확인하기 전까지 일시정지한다.

| 경로 | 내용 |
|---|---|
| `Originals/` | 생성 원본과 가져온 참조 파일 |
| `Metadata/<이미지 ID>.json` | 자산 정보, 프롬프트, 참조 목록, 생성 설정, 대화·요청 ID, API 사용량, 프로젝트 정보 |
| `ImageFlow.library.json` | 버전이 있는 전체 보관함: 프로젝트, 노드와 연결, 레시피, 이미지 목록, 작업 저널 |
| `Jobs.json` | 전송 경계와 복구 상태를 기록하는 작업 저널 |
| `Receipts/` | 원본 저장 직후의 복구 기록. 참조 이미지도 포함 |
| `Thumbnails/` | 원본에서 다시 만들 수 있는 미리보기 |
| `Library.store*` | SwiftData 메타데이터 캐시. 공개 JSON 복원 형식과 별개 |

보관함 전체를 백업한다. 앱 재설치 후 폴더를 선택하면 원본·참조·작업 기록을 복원한다. JSON은 UTF-8, 날짜는 ISO 8601이며 API 키와 로그인 세션은 포함하지 않는다. 원본이 없거나 손상된 보관함은 현재 보관함을 대체하지 않는다.

## 생성 진행과 레시피

이미지 프레임이 모이는 Canvas 애니메이션을 컬렉션, 노드 결과, 작업 상세에서 사용한다. 준비·전송·생성·수집 상태와 경과 시간을 표시하며 가짜 완료율은 사용하지 않는다. 애니메이션은 최대 24fps이고 동작 줄이기 또는 비활성 장면에서는 정지한다.

레시피는 검색 가능한 보관함에서 미리 보고 적용한다. 개인 레시피 저장·이름 변경·편집·삭제와 삭제 취소를 제공한다. 제품 촬영·브랜드 무드보드·참조 변형 템플릿을 포함하며 `{{이름}}` 변수는 별도 입력란으로 바뀐다. 프롬프트만 적용하는 것이 기본이며 생성 설정과 참조 교체는 선택 사항이다. 적용의 되돌리기·다시 실행을 지원한다.

## API 예상 비용

선택 모델, 크기, 품질, 장수, 요청 횟수에 따른 이미지 **출력** 비용을 생성 버튼 위와 노드 설정·실행 확인 화면에서 표시한다. 입력 프롬프트 및 참조 이미지 비용은 별도다. 자동 크기는 1024×1024 예시이며 실제 비용의 상한이 아니다. 자동 품질은 지원 품질의 범위로 표시한다. 스트리밍 부분 이미지 추가 비용은 설정된 최대 개수 기준이다.

2026-09-26 확인한 공식 [이미지 생성 계산 기준](https://developers.openai.com/api/docs/guides/image-generation#cost-and-latency)과 [API 가격표](https://developers.openai.com/api/docs/pricing)를 사용한다. GPT Image 2/2.5는 공개 계산기의 출력 토큰 계산식과 해당 모델의 토큰 단가를, 이전 모델은 공식 이미지 단가표를 적용한다. 세금·환율·계정별 할인은 반영하지 않는다. 요금이 바뀌면 이 가격표와 검증 예시를 갱신해야 한다.

## 검증

- 자동 테스트 76개 통과: Instant 전송 내용, 출력 비용 예시와 요청 수, 변수 치환, JSON 복원, 첨부 포함 복사, 손상·누락 원본과 기존 폴더 보호, 미리보기 재생성, 기존 WebKit 어댑터 회귀 검증.
- 기존 원본·첨부 78개를 Pictures 보관함으로 복사한 후 재시작 복원. 실제 새 생성 후 총 79개의 파일 해시 일치 확인. 이전 저장소 보존.
- 별도 임시 폴더에 `ImageFlow.library.json`과 `Originals`만 복사한 뒤 실제 앱으로 열었다. SwiftData·저널·영수증·미리보기 없이 이미지 79개, 프로젝트 12개, 레시피 1개, 작업 61개를 복원하고 미리보기 79개를 재생성했다. 검증용 대기열은 정지 상태로 유지했고 추가 전송은 없었다.
- 실제 배지 화면과 선택 DOM 확인. Instant 새 요청에 `n=`가 없고 도구 확인 시각이 저장됐으며 이미지 1장 수집 성공.
- 온보딩, 생성 상태, 레시피 변수 입력과 적용·되돌리기·다시 실행, API 비용 표시를 실제 앱에서 확인.
- 개발 Mac의 macOS 27.2 / Apple Silicon에서 서명된 개발 번들 빌드·실행. macOS 14~26의 실기기 검증은 수행하지 않았다.

개인 계정 화면을 포함한 진단 증거는 Git에서 제외한 `.runtime`에만 저장한다.

## 프로젝트 안의 참조와 생성 자리 (후속 개선)

- 외부 첨부 원본을 컬렉션에도 표시하고 ‘참조’ 배지로 구분한다. 프롬프트에서 첨부를 해제해도 해당 프로젝트에 가져온 원본은 남는다. 사이드바 개수와 대표 이미지에도 반영한다.
- 상단 생성 카드 대신 컬렉션의 실제 이미지 격자에 요청 장수만큼 자리표시자를 만든다. 슬롯 ID는 요청 ID와 이미지 순서로 유지하며, 도착한 결과만 해당 자리에서 교체한다. 실패·답변 도착도 해당 슬롯에서 작업 상세로 연결한다. 자리표시자는 이미지 선택·드래그 대상에서 제외한다.
- 워크플로 생성 노드 안에서도 요청 장수만큼 대기 이미지를 표시한다.
- 78개 테스트 통과. 일부 결과 수집 시 슬롯 유지, 실패 후 확인 알림 닫기, 숨긴 결과가 빈 슬롯으로 돌아오지 않는 동작을 검증했다.
- 실제 앱에서 알려진 검증용 이미지를 첨부로 가져오고 자동 4장 생성을 실행했다. 참조 1장 + 대기 4칸에서 참조 1장 + 생성 이미지 4장으로 바뀌는 것을 확인했다. 유료 API 생성은 하지 않았다.
