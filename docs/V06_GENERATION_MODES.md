# 0.6 — 생성 방식과 결과 모델 식별

2026-09-20, macOS 27.2 / Apple Silicon에서 검증.

## 생성 요청

- 설명이 있는 세 가지 선택 박스: 자동(요청당 4장), Sunburst (실험)(2장), Instant(1장).
- 자동·실험 방식은 비-Instant 설정을 사용하며, 특정 모델을 강제로 선택한다고 간주하지 않는다. 구성 비율이나 Sunburst 사용을 보장하지 않는다.
- `시안 개수`를 `요청 횟수`로 변경했다. 숫자 입력과 스테퍼를 지원하며, 요청 횟수 × 요청당 장수를 계산해 총 생성 장수와 버튼에 표시한다. 변형을 입력하면 비어 있지 않은 각 줄이 한 요청이다.
- 마지막 생성 방식은 저장된다. 이전 Sunburst/Flare 설정은 실험/Instant로 이전하며, 이전 작업의 기록과 장수는 보존한다.
- 여러 결과를 각기 저장하고 캔버스에 개별 배치한다. 요청보다 적게 도착하면 저장된 결과를 유지하면서 누락 장수를 알린다. 기존 대화 확인으로 나머지를 수집할 수 있다.

## picture_v2 직접 주입

사용자가 지정한 WKWEBVIEW_REPORT 4.2의 ProseMirror Pill DOM 주입 방법을 적용했다.

1. 프롬프트를 텍스트 노드로 구성하고 첫 문단에 `picture_v2` Pill을 삽입한다. `contenteditable=false`, `data-inline-selection-pill`, `data-id`, `data-symbol`, `data-keyword`, `data-system-hint-type`을 설정한다.
2. `inputType=insertHTML`인 `input`과 `change` 이벤트를 전달한 뒤 DOM 동기화를 기다린다.
3. 참조 업로드와 생성 방식 설정을 마친 뒤 Pill을 다시 확인한다.
4. 작업의 전송 경계를 디스크에 기록한 뒤, 별도 전송 단계에서 Pill을 재확인하고 전송한다.

+ 메뉴를 열거나 메뉴 이름으로 항목을 찾지 않는다. 프롬프트의 HTML 기호와 줄바꿈은 문자 그대로 보존한다. 주입 실패·Pill 소실 시 전송하지 않고 작업 오류로 알린다. 도구 주입은 생성 요청을 명시하는 방식이며 서비스가 항상 이미지를 반환한다는 보장은 아니다. 텍스트 응답 처리와 후속 요청은 유지한다.

## 결과 모델 식별

사용자의 최종 지시에 따라 이미지별 `parts[i].metadata.generation.gen_size`만 판별에 사용한다.

| gen_size | 표시 |
|---|---|
| smimage | Flare |
| image | Sunburst |
| 누락·알 수 없는 값·상충 | 확인되지 않음 |

`gen_size_v2`는 원시 기록 호환성을 위해 보관하지만 분류에 사용하지 않는다. 24/32/48 등 어떤 값도 `gen_size`의 판별을 변경하지 않는다. 요청 방식, 추론 수준, 이미지 크기·순서로 모델을 추정하지 않는다.

현재 대화 분기의 이미지 메타데이터를 원격 파일 ID로 각 결과에 연결한다. 과거 결과는 명시적인 ‘모델 정보 확인’으로 원본 파일 바이트의 SHA-256을 대조하며, 일치하지 않으면 판별하지 않는다. 메타데이터는 보관함·복구 영수증·내보내기에 함께 저장된다. 인증 토큰은 웹 페이지 내부에서만 사용한다.

## 검증

- `swift test`: 33개 통과. 요청 장수·영문 옵션·이전 기록 호환, 부분 결과 처리, 파일별 메타데이터·현재 분기 선별·인증 실패, gen_size 단독 분류, Pill 주입·문자 이스케이프·중복 방지·동기화 실패·전송 차단 포함.
- `script/build_and_run.sh --verify`: 빌드·실행 성공.
- 실제 ChatGPT 편집기에서 세 방식 모두 직접 주입한 Pill과 프롬프트가 설정 후에도 유지됨을 확인.
- 자동 4장, 실험 2장, Instant 1장의 실제 생성 및 개별 저장 확인. 세 요청을 별도 대화에서 동시에 실행.
- 직접 주입 적용 후 참조 이미지 1개를 첨부한 자동 요청 추가 검증: 한 대화의 4장 모두 저장. 결과의 `gen_size`는 모두 `image`, `gen_size_v2`는 32와 48이 섞였으며 모두 Sunburst로 판별.
- 이전 버전 이미지의 원본 SHA-256 대조로 메타데이터 복원과 Sunburst 표시를 확인. 대화 로딩 직후 이미지 카드가 늦게 나타나는 경우도 기다리도록 처리.
- 요청 횟수 3을 키보드로 입력하고 총 장수가 자동 12 / 실험 6 / Instant 3으로 바뀌는 것을 확인. 검증 후 1회로 복원하고 앱 재실행 후에도 자동 선택·1회 설정이 유지됨을 확인.
- 1100 × 760 밝은 화면에서 선택 박스와 고정된 총 장수·생성 버튼, 캔버스의 결과별 배치를 확인.

실제 계정 세션·대화 ID·인증 정보·생성 원본은 Git에 포함하지 않는다.
