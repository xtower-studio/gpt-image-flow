# 0.7 — macOS Liquid Glass

2026-09-20, macOS 27.2 / Xcode 27.0 / Apple Silicon에서 검증.

## 디자인

[Apple Liquid Glass 개요](https://developer.apple.com/documentation/technologyoverviews/liquid-glass)와 [적용 지침](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)에 따라 내비게이션·조작 도구와 이미지 콘텐츠를 구분한다.

- 표준 NavigationSplitView 사이드바, 도구 막대, 검색, 검사기, 시트는 시스템 외형을 사용한다. 도구 막대 배경을 강제로 숨기는 설정과 검사기의 불투명 배경을 제거했다.
- 도구 막대의 보기·후보 필터와 만들기·패널 전환 사이에 시스템 ToolbarSpacer를 넣었다.
- 캔버스 조작, 하단 선택·썸네일 크기, 알림에는 시스템 `glassEffect`를 적용한다. 가까운 커스텀 표면은 하나의 `GlassEffectContainer`에서 처리한다.
- 생성 버튼은 `glassProminent`, 새 프로젝트와 비교 창 완료 버튼은 `glass` 스타일을 사용한다.
- 이미지·비교 캔버스는 중립적인 일반 표면으로 유지한다. 생성 방식 설명 카드와 텍스트 편집기를 유리로 만들지 않는다. 이미지 수만큼 유리 렌더링 표면이 늘어나지 않는다.
- macOS 26 이상에서 새 API를 사용하고, macOS 14~15에서는 기존 버튼·재질로 대체한다. 투명도 감소 시 커스텀 유리 컨트롤은 불투명 표면으로, 고대비에서는 선명한 테두리로 표시한다. 별도의 반복 애니메이션이나 렌더링 타이머는 추가하지 않았다.

## 실제 SDK 링크

이 환경의 SwiftPM swiftbuild 백엔드는 최신 SDK로 컴파일하면서 실행 파일의 `LC_BUILD_VERSION.sdk`를 배포 대상인 14.0으로 기록했다. 그 상태에서는 최신 API를 직접 적용한 부분 외에 표준 컨트롤들이 이전 외형을 유지했다.

실행 스크립트가 `xcrun --show-sdk-version`으로 실제 SDK 버전을 읽고 `-platform_version macos 14.0 <SDK>`를 링크 옵션으로 전달하도록 수정했다. 빌드 후 `vtool -show-build`로 기록이 일치하는지 검사한다. 검증 환경에서는 `minos 14.0 / sdk 27.0`이며, 배포 최소 버전을 올리지 않고 표준 시스템 외형이 바뀐 것을 확인했다.

앱 번들 조립 후 로컬 개발용 ad hoc 서명을 적용하고 `codesign --verify --strict`로 검증한다. 실행 파일은 새 inode로 교체하여 이전 코드 서명을 캐시한 상태에서 덮어쓰지 않는다. 이는 배포 서명·공증과 별개다.

프로젝트의 실행·Codex Run 버튼은 `script/build_and_run.sh`를 사용한다. 컴파일에는 Xcode 26 이상 SDK가 필요하다.

## 검증

- 빌드·앱 번들 실행, 링크 SDK 및 번들 서명 검사 성공. 기존 ChatGPT 로그인 세션과 보관함 복원 확인.
- 밝은/어두운 모드, 1000 × 680 / 1100 × 760 / 1400 × 940 크기에서 컬렉션·캔버스 확인.
- 작은 창에서 이미지 선택 후 SplitView 최소 크기가 반복 재계산되던 문제 수정. 작업 영역이 자식 콘텐츠의 최소 크기를 상위 분할 뷰로 전파하지 않도록 명시적인 유연한 프레임을 설정했다.
- 수정 후 같은 프로세스에서 작은 창 선택, 정보/만들기 탭 전환, 검사기 가리기/표시, 창 크기 변경, 비교 시트 열기/닫기 확인.
- 개발용 앱 내부 미리보기에서 커스텀 유리의 투명도 감소·고대비 대체 표면을 확인하고 기본 상태로 복원. 시스템 접근성 설정은 변경하지 않았다. 표준 시스템 컨트롤과 구형 macOS의 실제 접근성/재질 렌더링은 별도 OS 환경에서 검사하지 않았다.
- `swift test`: 기존 33개 테스트 통과. 생성·저장·메타데이터 로직은 수정하지 않았다.

스크린샷과 로컬 진단은 `.runtime/v07-*`에 보관하며 계정 데이터·생성 원본을 저장소에 추가하지 않는다.
