# 0.8 Studio 패널 재설계

기존 오른쪽 패널은 작은 각진 필드, 분리된 참조 상자, 큰 독립 선택 카드가 함께 있어 시스템 Liquid Glass 도구 막대와 어울리지 않았다. 재질뿐 아니라 입력 순서, 정보 밀도, 선택 상태와 행동의 위계를 재구성했다.

## 화면 구조

- 만들기·정보·작업 전환은 같은 크기의 아이콘과 제목으로 구성한다. 선택한 탭에만 시스템 유리를 사용한다.
- 프롬프트와 참조 이미지는 하나의 입력 카드다. 프롬프트를 쓰고 바로 아래에서 참조를 더한다. 파일 드롭 대상은 카드 하단의 참조 영역에만 있다.
- 생성 방식은 하나의 그룹 안에 놓인다. 아이콘, 이름, 요청당 장수, 설명 순서가 동일하고 선택은 체크와 약한 강조색으로 표시한다.
- 화면 비율과 배경은 두 개의 같은 크기 옵션 카드로 나란히 배치한다. 값 선택에는 네이티브 메뉴를 사용한다. 요청 횟수는 키보드 입력과 증감 버튼을 모두 제공한다.
- 총 이미지 수와 생성 버튼은 패널 하단에 고정한다. 작은 창에서는 설정 내용만 스크롤된다.
- 정보 탭은 미리보기 → 이어 만들기 → 프롬프트 → 생성 정보 → 파일 작업 순서다. 원시 모델 식별 값은 펼쳐서 확인한다.
- 작업 탭은 일정한 여백의 카드 목록이며, 텍스트 답변과 후속 입력에도 동일한 패널 구성 요소를 적용한다. 기록 미리보기는 사용자가 입력한 프롬프트를 우선 표시한다.

## 재질과 일관성

Apple의 [Liquid Glass 개요](https://developer.apple.com/documentation/technologyoverviews/liquid-glass)와 [커스텀 뷰 적용 가이드](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)를 따른다. 유리는 탐색·행동에 사용하고 입력·정보 카드는 시스템 배경색을 사용한다. 패널 바깥 여백 16pt, 주요 섹션 간격 22pt, 기본 카드 모서리 18pt를 기준으로 중첩 요소의 모서리를 줄인다. 갤러리·비교·캔버스의 모서리도 조정했다.

네이티브 텍스트 편집, IME, 실행 취소, 포커스 요청과 초안 소유권을 유지한다. 새 입력·옵션 구성 요소는 필요한 바인딩과 동작만 전달받는다. 프레임마다 동작하는 타이머나 새로운 WebView를 추가하지 않았다. macOS 26 이상은 실제 Liquid Glass를 사용하고 이전 OS의 재질 대체 경로를 유지한다.

## 검증

개발 Mac macOS 27.2 / Apple Silicon에서 확인했다.

- 기본 1280×840, 작은 1000×680 창의 실제 실행 화면. 만들기·정보·작업·텍스트 답변, 갤러리와 캔버스 확인.
- 밝은 모드와 어두운 모드 확인. 앱 내부 미리보기로 커스텀 재질의 투명도 감소와 대비 강화 대체 경로 확인 후 원복. 시스템 전체 접근성 설정을 변경한 테스트는 아니다.
- 키보드로 요청 횟수 3 입력: 자동 12장, Sunburst (실험) 6장, Instant 3장 확인 후 기존 값 복원.
- 화면 비율 1:1, 배경 투명 메뉴 선택 및 표시 확인 후 자동으로 복원.
- 실제 이미지 드래그: 프롬프트 위에서는 참조 추가 없음, 참조 영역에서는 한 번 추가됨, 제거 후 복원. 자산 수 37개 유지, 해당 프로젝트 데이터가 검증 전과 동일함을 확인.
- 기존 자동 테스트 33개 통과. 최신 SDK 링크·로컬 번들 서명 검사를 포함한 빌드 및 실행 성공.

실제 이미지 생성 엔진과 전송 방식은 변경하지 않았다. 이번 검증에서는 새 생성을 요청하지 않았다. 구형 macOS에서의 실제 실행과 VoiceOver 전체 탐색 검증은 수행하지 않았다. 실행 화면 증거는 사용자 이미지가 포함되므로 로컬 `.runtime`에만 보관한다.


## 0.8.1 글자 크기와 계층

제목과 설명이 10–12pt에 몰려 있던 문제를 수정했다. `StudioTypography`를 공통 기준으로 사용한다.

| 역할 | 크기·굵기 | 적용 |
|---|---|---|
| 패널 제목 | 17pt semibold | 이미지 제목, 작업 기록, 답변 상태 |
| 섹션 제목 | 15pt semibold | 프롬프트, 생성 방식, 출력 설정, 생성 정보 |
| 본문·주요 선택값 | 14pt regular / medium | 네이티브 입력문, 프롬프트·답변, 모델명, 갤러리 제목 |
| 주요 행동 | 14pt semibold | 생성·후속 요청 버튼 |
| 보조 설명·컨트롤 | 13pt regular / medium | 모델 설명, 참조 안내, 탭과 요청 횟수 라벨 |
| 메타정보 | 12pt regular | 장수, 시간, 크기, 파일 형식 |

섹션 제목은 기본 글자색으로 올리고, 설명과 메타정보에만 보조색을 사용한다. 입력문과 긴 본문은 4pt 줄 간격을 적용한다. 네이티브 AppKit 입력기에도 같은 본문 크기와 줄 간격을 적용했다. 모델 설명에서는 장수 배지와 중복되는 문구를 줄였다. 기본 창에 출력 설정과 요청 횟수가 보이도록 프롬프트의 빈 공간과 섹션 간격을 조정하고, 커진 갤러리 캡션에 맞춰 셀 높이를 확보했다.

0.8.1 빌드·실행 성공. 1280×840 밝은 모드의 만들기 화면, 어두운 정보 화면, 1000×680 어두운 모드의 작업 기록과 만들기 화면·출력 설정 스크롤을 실제 앱에서 확인했다. 기능 변경 없는 표시 수정이므로 자동 테스트를 새로 작성하지 않았다. 위 33개 자동 테스트 통과 기록은 0.8 검증 결과다.
