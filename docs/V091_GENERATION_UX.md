# 0.9.1 · 생성 옵션과 첨부 UX

2026-09-22. 생성 방식과 비용 안내를 단순화하고, 프롬프트에 직접 참조 이미지를 놓는 흐름을 복원했다.

## 화면과 동작

- 생성 방식은 **자동 · 고급 · 빠르게**다. 자동 설명은 ‘가장 적절한 모델을 자동으로 선택’이며, 웹의 xhigh 설정은 유지한다. 빠르게는 기존 Instant 동작을 유지한다. 저장된 열거형 값은 바꾸지 않아 기존 프로젝트·레시피·작업 기록을 읽을 수 있다.
- 모델을 알 수 없는 결과는 모델 행·배지·설명·구분점을 생략한다. 컬렉션, 캔버스, 비교, 정보 패널과 접근성 설명에 동일하게 적용한다. API 결과만 명시적으로 요청한 모델 이름을 표시한다.
- 자동·빠르게의 화면 비율과 배경 메뉴는 하나의 메뉴에 항목을 직접 표시한다. 메뉴 안의 Picker로 발생하던 중복 하위 메뉴를 제거했다.
- 프롬프트 텍스트와 카드 여백, 기존 참조 영역 모두 파일 드롭을 받는다. 텍스트 편집기는 파일 경로를 글자로 삽입하지 않고 참조 가져오기로 전달한다. 파일 드롭은 실제 대상 영역에서 놓았을 때만 반영한다. 중복 파일은 기존 가져오기 경로에서 제거한다.
- ‘API 사용료는 OpenAI가 직접 청구합니다. Image Flow는 어떠한 수수료도 받지 않습니다.’와 ‘앱 수수료 0원’을 연결·고급 옵션·설정 화면에 표시한다. 생성 버튼 아래에도 직접 청구와 수수료 없음을 표시한다.

## 고급 기본값과 모델

새 API 설정은 **Sunburst · High · 자동 크기 · 요청당 2장**이다. 이미 저장한 사용자 설정과 대기 중인 작업을 새 기본값으로 덮어쓰지 않는다. ‘API 옵션 기본값으로 복원’에서 새 기본값을 적용할 수 있다.

Images API는 별도 추론 설정을 받지 않는다. 요청의 High는 `quality: high`로 적용하며 UI에는 ‘품질’로 표시한다. API 작업 기록에 웹용 추론 단계를 새로 넣지 않는다.

2026-09-22 현재 제공 중인 이미지 모델을 선택할 수 있다.

| 모델 | 고정 버전 | 비고 |
|---|---|---|
| Sunburst | 2026-09-08 | 기본값, 세밀한 수정 |
| Flare | 2026-09-08 | 빠른 이미지 생성 |
| GPT Image 2 | 2026-04-21 | 입력 충실도는 서버가 자동으로 높게 처리 |
| GPT Image 1.5 | — | 2026-12-01 종료 예정 |
| GPT Image 1 | — | 2026-10-23 종료 예정 |
| GPT Image 1 Mini | — | 2026-12-01 종료 예정 |
| ChatGPT Image (이전) | — | `chatgpt-image-latest`, 2026-12-01 종료 예정 |

종료가 예정된 모델은 선택 화면에 날짜를 안내하고 종료일 이후에는 새 요청을 막는다. 이미 종료된 DALL·E 2·3은 선택지에 넣지 않는다. 실제 접근 여부는 사용자의 OpenAI 계정 권한에 따른다. 연결 확인은 특정 Sunburst 권한을 전제로 하지 않고 모델 목록 조회로 인증을 확인한다.

Sunburst·Flare는 XHigh·Max를 포함하고, 이전 모델은 지원하는 품질만 표시한다. GPT Image 2 이상은 자유 크기, 이전 모델은 표준 크기를 제공한다. 모델 전환 시 지원하지 않는 품질·크기·입력 충실도는 유효한 설정으로 바꾸고 화면에서 알린다. API 전송 전에도 같은 제약을 검증한다.

크기 메뉴는 비율과 긴 변 기준 K 표기다. 예: 1024×1024 → **1:1 · 1K**, 1536×1024 → **3:2 · 1.5K**, 2048×1152 → **16:9 · 2K**, 3840×2160 → **16:9 · 4K**. 4K는 UHD 기준이다. 정확한 가로·세로 입력은 모든 API 옵션의 별도 펼침 영역에 남겨 둔다.

## 검증

- 로컬 자동 테스트 **52개 통과**. 새 기본값, 기존 설정 복원, 총 장수, 7개 모델과 고정 버전의 전송 매개변수, 모델별 제약, 모델 전환, 비율·K 표기, 모델 미표시를 포함한다.
- 실제 앱에서 자동·빠르게의 화면 비율 메뉴와 배경 메뉴를 열어, 항목에 하위 메뉴가 없는 것을 접근성 트리로 확인했다.
- 실제 이미지 드래그로 원위치 드롭 → 첨부 없음, 프롬프트 드롭 → 참조 1개, 재드롭 → 중복 없음, 참조 영역 드롭 → 정상 첨부를 확인했다. 프롬프트 내용은 변하지 않았고 검증 후 참조를 복원했다.
- 앱에서 기본값 복원 후 Sunburst·High·자동·2장과 총 2장을 확인했다. 모델 선택 메뉴에 7개 모델이 표시된다.
- macOS 27.2에서 개발 번들 빌드·실행을 확인했다. 이번 수정 검증에서 추가 유료 이미지는 생성하지 않았다. 모든 모델·옵션 조합의 실제 유료 생성까지 검증했다는 의미는 아니다.
