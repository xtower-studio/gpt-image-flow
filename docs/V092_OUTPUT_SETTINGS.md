# 0.9.2 출력 설정

- 화면 비율과 해상도(K)를 별도로 선택한다. 품질(High 등)은 그대로 독립적인 옵션이다.
- 선택한 모델과 비율이 지원하는 해상도만 제공한다. 비율 변경 시 같은 해상도를 유지할 수 있으면 유지하고, 불가능하면 해당 비율의 기본 해상도를 선택해 즉시 표시한다.
- 자동은 API의 `size: auto`를 유지한다. 자동 상태에서 해상도를 직접 고르면 그 해상도를 지원하는 기본 비율도 함께 표시한다. 비율 메뉴의 자동으로 되돌릴 수 있다.
- 기존 사용자 지정 크기는 열거나 저장할 때 바꾸지 않는다. 유연한 크기를 지원하는 모델에는 3:2·2:3의 약 2K 프리셋(2016×1344, 1344×2016)을 추가했다.
- 정확한 크기 직접 지정은 화살표, 제목, 오른쪽 빈 공간을 포함한 전체 행으로 펼치거나 접는다.
- 고급 출력 설정은 자동 모드와 같은 타일·개수 입력 형태를 사용하며, 수수료 안내는 옵션 하단에 배치한다.

검증: Swift 테스트 55개 통과. 모델별로 제공하는 모든 비율·해상도 조합의 유효성과 API 전달값, 비율 변경 시 해상도 유지, 자동 복원, 사용자 지정 크기 보존을 확인했다. 실제 앱에서 16:9 → 4K 선택 후 3840×2160을 확인하고, 제목 텍스트와 오른쪽 빈 공간 클릭으로 직접 지정 행의 펼침·접힘을 확인했다. 추가 유료 API 생성은 수행하지 않았다.
